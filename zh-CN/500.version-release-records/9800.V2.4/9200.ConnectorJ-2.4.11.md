# OceanBase Connector/J V2.4.11

## 版本信息

- 发布时间：2024 年 5 月 11 日
- 版本号：V2.4.11

## 版本定位

JDBC 2.4.11 版本新增对 Oracle 模式下 `sdo_geometry` 复杂类型的支持，实现了 `setMaxRows` 接口，并引入了新的参数 `mapDateToTimeStamp`，从而加强了 OB-JDBC 与 Oracle 驱动的兼容性。

## 功能增强

- 新增对 Oracle 模式 `sdo_geometry` 复杂类型的支持。

- Oracle 兼容性改进：支持 `mapDateToTimeStamp` 配置项。该选项允许对 DATA 类型数据的展现形式进行配置。通过设置 `mapDateToTimeStamp=false`，使用 `getString` 方法获取字段值时，可以仅获取日期部分，例如 "2023-10-24"（默认情况下获取的数据形式为 "2023-10-24 00:00:00"）。

- 在 Oracle 模式下，`setMaxRows` 接口生效，返回指定结果集的行数。


### 新增 URL 参数

| 参数名称 | 状态 | 默认值 | 描述 |
|----------|------|--------|------|
| mapDateToTimeStamp | 新增 | true | OB-JDBC 的特有参数。设置为 `true` 时，Oracle 模式下 Date 数据类型将包含时分秒信息；设置为 `false` 时，则只显示日期部分。|


## 缺陷修复

- 解决了编译存储过程时报告 type 未声明的错误，尽管该 type 实际上已经存在。
- 解决了使用 `ResultSet #getBigDecimal` 方法时出现的 `Round Necessary` 异常问题。
