# OceanBase Connector/J V2.4.9

## 版本信息

* 发布时间：2024 年 3 月 29 日
* 版本号：V2.4.9

## 版本定位

JDBC 2.4.9 将 logback-classic 组件从 1.2.8 升级到 1.4.14，防止用户安全扫描出现漏洞。支持 Oracle 模式 out-row lob 流式结果集读取功能。调整一系列接口兼容逻辑，增强 OceanBase Connector/J 与 MySQL、Oracle 驱动的兼容性，同时修复了一些重要缺陷，提升产品稳定性。

## 新增特性

* 支持 Oracle 模式 out-row lob 类流式结果集读取。
* Oracle 兼容：

  * OceanBase 数据库 Oracle 租户下，调整 `getTables` 接口拼接的 SQL。
  * `acceptsURL(null)`、`connect(null, null)` 两者 `url` 参数为空时，抛出 `NPE` 异常。
  * 调整 `number` 类型 （`p < s`）时，`getLong`、`getDouble` 等 `get` 类接口逻辑，兼容 Oracle 原生驱动，包括文本协议和 ps 协议。
  * `float` 列，使用 `getColumnClassName` 获取信息调整为 `Double` 类型。

* MySQL 兼容：

  * MySQL 租户下，调整 `getWarnings` 接口返回值以兼容 MySQL 原生 JDBC 驱动。
  * 参数 `emptyStringsConvertToZero=true` 时，对缺失 `emptyStringsConvertToZero` 处理的 `getFloat`、`getDouble`、`getBigDecimal` 等 `get` 方法增加处理逻辑，而不是直接抛异常。

## 兼容性变更

### 产品行为变更

* `setTransactionIsolation`、`supportsTransactionIsolationLevel` 两个方法均不再支持 `READ_UNCOMMITTED` 隔离级别。
* `getDatabaseProductName` 修改返回逻辑，固定返回 OceanBase，而不是 MySQL 或 Oracle，通过 `useCompatibleMetadata` 参数兼容旧版本行为；`getDatabaseProductVersion` 返回 `ob_version()` 函数内容。

### URL参数变更

新增以下 URL 参数：

| Option 名称 | 状态 | 默认值 | 描述 |
|-------------|------|-------|------|
| useCompatibleMetadata | 新增 | false | 默认配置下，`getDatabaseProductName` 接口返回 OceanBase。</br>为 `true` 时，根据租户模式，强制返回 MySQL/Oracle。</br>OceanBase Connector/J 特有参数。|
| remarksReporting | 新增 | false | 默认配置下，Oracle 租户 `getTables()` 和 `getColumns()` 接口关联 `comments` 表。</br>设置为 `true` 时，关联 `comments` 表。</br>OceanBase Connector/J 特有参数。|

### 缺陷修复

本次迭代共修复 13 个缺陷，主要修复问题如下：

* 修复 PL/SQL 参数为 Json 类型时，调用 `getParameterMetaData` 报空指针异常的问题。
* 修复参数 `yearIsDateType=true/false` 下, 对值为 "0000" 的 `YEAR` 类型，处理结果跟 MySQL 不一致问题。
* 修复驱动调用 `getColumnType` 获取 `LONGBLOB` 类型的 `length`，结果不正确的问题。
* 修复开启连接池时，建联发送 SQL 报错问题。
* 修复配置参数 `useInformationSchema=true` 时，调用 `getCrossReference` 等接口报错问题。
* 修复 `useServerPrepStmts=true&useOraclePrepareExecute=true` 下，包含 Hint 的查询，解析错误问题。
* 修复 `LOAD DATA LOCAL INFILE`，当 SQL 为 `C:\\\\Users...` 时的报错问题。
* 修复 `LOAD DATA LOCAL INFILE` 带有 `parallel` Hint 时的报错问题。
* 修复设置参数 `rewriteBatchedStatements=true` 时，`--` 参数没有拼接括号，被视为注释的问题。
* 修复 `getProcedures` 方法，返回的入参列表不全问题。
* 修复 JDBC 发送 16MB 包时，SQL 夯住问题。
* 修复跑批场景下游标超限问题。
* 修复调用 Package 返回结果不正确的问题。
