# OceanBase Connector/J V2.4.12

## 版本信息

* 发布时间：2024 年 8 月 02 日
* 版本号：V2.4.12

## 版本定位

JDBC 2.4.12 完成了 `ResultSetMetaData` 的 `scale`，`precision`，`length` 的重新适配，支持 Oracle 模式下的 `getProcedureColumns` 返回正确结果集，同时优化了 `getDate` 接口的性能。

## 新增特性

* 基于兼容模式，重新适配 `ResultSetMetaData` 的 `scale`，`precision`，`length`。

* 优化 `getDate` 接口的性能。

## 兼容性变更

### 产品行为变更

Oracle 模式下，`getProcedureColumns` 返回正确结果集。

### 新增 URL 参数

|  参数名称 | 状态 |  默认值 | 描述 |
|----------|------|--------|------|
| obDateTypeOptimization（OB-JDBC 参数）| 新增 | False | 对于 `getDate` 方法使用从 Byte 数组获取值，而非转为字符串在进行截取。|
| useNewResultSetMetaData（OB-JDBC 参数）| 新增 | False | 元数据信息兼容原生 MySQL JDBC。|

## 缺陷修复

* 修复 XA 事务 `recover` 接口返回为空的问题。
* 修复 ArrayBinding delete 场景下，开启 PS 二合一协议及 `rewriteBatched`，JDBC 连接 OB 4.2.x 跟连接 OB 3.2.x，报错不一致问题。
* 修复 `useServerPrepStmts=true&usePieceData=true&useArrayBinding=true` 配置下，`executeBatch` 报错问题。
* 修复 Oracle 模式下，`FetchSize > MaxRows` 时，`setFetchSize` 报错问题。
* 修复 MySQL 模式下，`FetchSize > maxRows`，可更新结果集查询列信息使用游标结果集报错问题。
* 修复 `setCharacterStream(2)` 构造 `clob` 数组越界异常问题。
* 修复 PS 二合一协议、`useArraybinding=true` 时 `executeBatch` 报错问题。
* 修复 PS 模式下，多线程使用一个 `conn` 时获取结果集为空时夯住的问题。
* 修复使用 PL 复杂类型的同义词构造存储过程入参时，报错 “Current position is after the last row” 的问题。
